# Barberia R Cartagena

Web estatica para Barberia R en Cartagena.

## Archivos principales

- `index.html`: fichero unico principal de la web, listo para desplegar.

La web usa HTML, CSS embebido, JavaScript vanilla y Supabase JS por CDN.

## Supabase

La pagina puede mostrar barberos locales aunque Supabase no este disponible. Para activar reservas reales hay que configurar un proyecto Supabase con las tablas y politicas RLS esperadas por el JavaScript.
